# 本地启动器托管，文件为唯一真源

页面必须由本地 HTTP 服务托管，不能双击以 `file://` 打开。配套提供一个双击即用的启动器
（Python），负责静态托管、工程 JSON 读写、文件变更推送与 AI 请求代理。

原因是硬性的：`file://` 页面的 origin 是 opaque origin，规范要求文件选择器直接以 `SecurityError` 拒绝，
且 `Origin: null` 的跨域请求会被 CORS 拦截。这会让"读写工程文件"与"AI 直连"同时失效，
而这两点正是本工具的核心诉求。改用 `http://localhost` 后两者都成立，
AI 请求再经本地代理转发以彻底绕开各家 API 的 CORS 差异，API Key 也得以存放在本地配置文件中而非浏览器里。

页面在检测不到本地服务时自动降级为受限模式（手动导入/导出 JSON、AI 走 prompt 中转），
以保证这个 HTML 文件在任何情况下都打得开。
